# Playwright Automation Testing Project

## About the Project
This is my Playwright automation testing practice project using TypeScript.

## Technologies Used
- Playwright
- TypeScript
- Node.js
- Git and GitHub

## Project Structure
- `tests/` – Automated test cases
- `playwright.config.ts` – Playwright configuration
- `package.json` – Project dependencies and scripts
- `.github/workflows/` – GitHub Actions workflow files

## How to Run the Tests
1. Clone this repository.
2. Install dependencies:
   `npm install`
3. Run tests:
   `npx playwright test`
4. Generate and open the HTML report:
   `npx playwright show-report`

## Purpose
This project demonstrates my practice of Playwright automation testing, test execution, reporting, and version control.
